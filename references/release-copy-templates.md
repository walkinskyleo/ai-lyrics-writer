# 五端发布文案模板与措辞规范

每首歌必须配套以下五端发布物料，直接可用。所有文案**禁用问句形式**（用户偏好），以陈述式情绪共鸣为主。

## 一、抖音标题

### 规范
- 1 条，15 字以内；
- 非问句、情绪共鸣、引导点赞互动；
- 可包含数字、对比、冲突，制造点击欲；
- 结尾可加引导互动词（"替那个…的人""听懂的人…"）。

### 模板
- 「X 是嘴硬，Y 才是真心」
- 「听懂这首歌的人，心里都住着 X」
- 「替那个还在 X 的人，点个赞」
- 「原来 X，才是 Y」
- 「X 的人，都听懂了这首歌」

### 示例
- 「说散就散是嘴硬，翻聊天记录才是真心」
- 「听懂这首歌的人，都还没放下」
- 「替那个还在练习告别的人，点个赞」
- 「原来错过，才让人懂得珍惜」
- 「嘴硬的人，都听懂了这首歌」

## 二、抖音话题标签

### 规范
- 3-5 个，#号开头，无空格；
- 组合：1 个大类 + 1 个情绪类 + 1 个内容类 + 1-2 个长尾类；
- 优先选流量大的标签，避免过于小众。

### 常用标签库
- 大类：#伤感音乐 #原创音乐 #流行音乐 #音乐推荐 #好歌分享
- 情绪类：#意难平 #遗憾 #治愈 #破防 #深夜emo #失恋 #想念
- 内容类：#歌词 #音乐现场 #翻唱 #原创歌曲 #汽水音乐
- 长尾类：#男生伤感 #一个人听 #耳机党必听 #宝藏歌曲 #单曲循环

### 示例组合
- `#伤感音乐 #意难平 #歌词 #原创音乐 #深夜emo`
- `#治愈音乐 #遗憾 #好歌分享 #汽水音乐 #单曲循环`

## 三、小红书文案

### 规范
- 1 条，50-100 字；
- 文艺氛围感，带 2-3 个 emoji（用户未禁止 emoji，小红书平台习惯）；
- 结构：金句开头 + 情绪描述 + 互动引导；
- 配 3-5 个话题标签。

### 模板
```
「金句 Hook」
情绪描述（2-3句，画面感+情绪）
🎧 适合深夜一个人听
💬 你心里住着的那个人，现在还好吗
#话题1 #话题2 #话题3
```

### 示例
```
「他字字未提喜欢，你句句都是我愿意」
单向奔赴的人，大概都懂这种委屈吧。
他随手一句晚安，你翻来覆去一整晚；他字字未提喜欢，你句句都是我愿意。
🎧 适合深夜一个人循环
💬 你还在等那个人的消息吗
#伤感音乐 #意难平 #歌词 #原创音乐 #深夜emo
```

## 四、朋友圈文案

### 规范
- 1 条，短句高级，氛围感拉满，15-30 字；
- 可直接复制发布，不依赖歌曲上下文也能独立成立；
- 禁用问句，用陈述式；
- 可带 1 个 emoji 或不带。

### 模板
- 「金句 Hook」
- 「X 是 X，Y 是 Y」
- 「后来才懂，X」
- 「X 的人，都 X」

### 示例
- 「说散就散是嘴硬，翻聊天记录才是真心。」
- 「我把备注改回全名的那天，把你也还给了人群。」
- 「后来才懂，最疼的不是告别，是没说出口的话。」
- 「放不下的人，最擅长把苦说成甜。」

## 五、歌单简介

### 规范
- 1 条，50 字以内；
- 故事解读 + 情绪内核，温柔走心；
- 适合放在歌单介绍、作品简介、平台简介。

### 模板
- 「写给每一个 X 的人。X，X。」
- 「这首歌，写给 X。X，X。」

### 示例
- 「写给每一个在单向奔赴里委屈自己的人。他字字未提喜欢，你句句都是我愿意。」
- 「写给每一个嘴硬的人。我真的没事说了一百遍，眼泪却比嘴诚实。」
- 「写给每一段后知后觉的青春。原来错过，才让人懂得珍惜。」

## 六、封面文案

### 规范
- 主标题 1-4 字（大字，视觉核心）；
- 副标题 1 句（8-12 字，小字，情绪点题）；
- 主标题优先用歌名或核心意象词；
- 副标题可用副歌 Hook 金句。

### 模板
```
主标题：「X」（1-4字）
副标题：「X，X」（8-12字金句）
```

### 示例
- 主标题：「字字句句」/ 副标题：「他未提喜欢，你全是我愿意」
- 主标题：「我没事」/ 副标题：「眼泪只是风吹的」
- 主标题：「还要多远」/ 副标题：「才能走进你的心」
- 主标题：「后知后觉」/ 副标题：「原来错过才懂珍惜」
- 主标题：「富士山下」/ 副标题：「看过你就足够」

## 七、封面 AI 绘画联动（可选）

封面文案确定后，可联动 AI 绘画生成封面：
- 主标题大字居中或底部，副标题小字；
- 画面风格按曲风匹配（伤感流行用暗色调+光影、民谣用暖色调+胶片质感、电子用赛博朋克霓虹）；
- 核心意象可入画（如"半杯冷茶""富士山""行星""旧车票"）；
- 提示词需包含：画面主体、色调、光影、构图、字体风格、文字内容。
