# 🎵 Ai Lyrics Writer（AI 歌词创作器）

**原曲主题复刻 + 全新原创填词・Suno 适配・发行级・抖音爆款潜质版**

基于任意公开发行歌曲，保留原作核心情绪内核与段落结构骨架（段落顺序、每段行数、每句节奏），100% 原创文字与意象，产出**可直接用于 Suno 编曲、歌曲发布、抖音 / 小红书 / 朋友圈多平台推广**的标准化 MD 成品 + 完整发布物料包。

> 版本：v3.5（2026-09-10）｜ 形态：豆包 Agent Skill ｜ 开源协议：MIT



***

## ✨ 功能特性



* **原曲复刻填词**：保留原曲情绪内核 + 结构骨架，文字 100% 原创，规避抄袭，可直接套原曲旋律演唱

* **发行级创作标准**：副歌金句 Hook（可拆行）、统一韵脚（开口音优先）、情绪递进与爆发、Call-back 首尾闭环、具象画面点缀（整首 ≤4 句，不设下限）、口语化直给表达

* **A/B 双版副歌**：A 版炸版直接（适配抖音）、B 版克制文艺（适配歌单 / 朋友圈），用户二选一；未指定则两版都给

* **参数化创作**：曲风（流行抒情 / R\&B / 民谣 / 说唱 / 古风 / 电子）、主题（爱情 / 友情 / 亲情 / 成长 / 城市孤独 / 治愈）、语言（国语 / 粤语 / 英文）、人声风格参考、Suno 版本、BPM、结构模板（跟随原曲或 ABAB/ABABCB/ACBACB）、批量生成

* **Suno 直配**：结构化编曲 Prompt（Style/Vocal/Instruments/Mood）+ 英文段落标签，可直接粘贴

* **五端发布物料**：抖音标题 + 话题、小红书文案、朋友圈文案、歌单简介、封面文案，一次配齐

* **自动质量门禁**：原创性 n-gram 自检（默认阈值 10%，GUI 可自由设定）+ 可唱性评分（≥60 分 / 硬门禁），不达标自动拦截

* **生成记录闭环**：自动记录生成日志、参考歌去重库（自动随机检索优先未用过的歌）、用户偏好分析（A/B 偏好、曲风偏好、质量趋势）

* **可视化 GUI**：图形界面配置参数、一键生成精简指令、全量作品列表（日期 / 标题 / 参考歌 / 评分 / 路径，支持搜索）、状态栏（去重库 N 首 / 记录 M 条 / 存储目录）、导出记录 CSV、整体滚动界面

## 🚀 快速开始

### 方式一：作为豆包 Skill 使用（推荐）

将本仓库整个目录放入豆包 Agent 工作区的技能目录（如 `.user_skills/` 或 `.skills/`），在对话中直接说出参考歌曲与需求即可触发本技能，例如：



```
帮我用《体面》-于文文 改写成一首新歌，伤感流行，副歌要 A 版

写一首类似《孤独患者》的歌，主题城市孤独，粤语

参考《说散就散》，批量生成 3 首，风格分别流行/R\&B/民谣
```

未指定参考歌曲时，技能会自动从**已用参考歌库去重**后随机检索一首匹配主题的伤感流行歌曲（全用过后选使用次数最少者）。

### 方式二：可视化界面（推荐）

**双击 skill 根目录的&#x20;**`启动创作器.bat`（自动定位 Python、无黑框窗口启动），或命令行运行：



```
python scripts/lyrics\_gui.py
```

配置存储目录与创作参数 → 生成**一句话精简指令**（全部参数拼入，执行规范由 skill 自动遵循）→ 复制发给 AI 执行 → 作品列表查看全部生成记录（双击打开、搜索、导出 CSV）→ 快捷工具跑检测 / 统计。

### 方式三：命令行直接调用脚本



```
\# 原创性自检（默认阈值 10%，可配）

python scripts/originality\_check.py 成品歌词.md 原曲歌词.txt --ngram 4 --threshold 10.0

\# 可唱性检测 + 质量评分（≥60 分且硬门禁通过为 PASS）

python scripts/singability\_check.py 成品歌词.md

python scripts/singability\_check.py 成品歌词.md --json   # JSON 输出

\# 批量检测（一次进程完成多首成品的原创性+可唱性+记录）

python scripts/batch\_check.py batch.json \[--record]

\# 生成记录管理

python scripts/log\_generation.py record --song "孤独患者-陈奕迅" --title "千百种" --path "成品.md" --originality 0.59 --singability 88 --style "流行抒情" --theme "城市孤独" --bpm 80 --structure "ACBACB" --chorus A

python scripts/log\_generation.py list          # 全部记录

python scripts/log\_generation.py search 关键词   # 搜索

python scripts/log\_generation.py stats          # 统计

python scripts/log\_generation.py preferences    # 用户偏好分析（≥3 条记录）

python scripts/log\_generation.py check-song "歌名-歌手"   # 查参考歌是否用过

python scripts/log\_generation.py export 生成记录.csv      # 导出记录为 CSV（Excel 可直接打开）
```

## 🎯 自动执行创作流程（12 步）



1. **歌词检索分析** —— 获取原版歌词，拆解主题 / 情绪 / 故事线 / 段落结构，记录行数与节奏作为填词骨架（未指定参考歌则去重后随机检索）

2. **曲式结构设计** —— 4/4 拍、BPM 60-108、结构模板（未指定则**跟随原曲**；或 ABAB / ABABCB / ACBACB）、总小节 60-80、每段 ≥4 小节

3. **主题复刻创新** —— 保留原曲情感主题与结构骨架，文字意象 100% 原创

4. **韵脚与 Hook 设计** —— 明确韵脚方案（开口音优先），设计 8-12 字可传播金句（可拆行合计 8-16 字）

5. **精细化填词** —— 每句 5-12 字留气口，预副歌 / 副歌字数梯度，融入热门破防金句

6. **A/B 副歌输出** —— 同一首歌 2 版副歌（A 炸 B 克制），未指定则两版都给

7. **标准化内容补齐** —— 5 个备选歌名（副歌有对应意思句）、创作思路、结构化 Suno Prompt、歌曲简介

8. **发布物料生成** —— 五端发布物料

9. **原创性自检** —— `originality_check.py` 比对，重复率 <10% 为 PASS（阈值可在 GUI 自由设定）

10. **可唱性自检 + 评分** —— `singability_check.py`，≥60 分且硬门禁通过

11. **Suno 格式排版** —— 英文段落标签 + 标准 MD 模板导出（.md）

12. **生成记录** —— `log_generation.py record` 自动归档并更新去重库

## 🧪 检测口径说明（v3.4 放宽版）

检测规则与创作规范完全对齐，消除 "合格成品被 FAIL" 的误伤：



| 检测项  | 口径                                                          |
| ---- | ----------------------------------------------------------- |
| 情绪递进 | **容差制**：预副歌均值 ≤ 主歌 + 2.0 字，副歌均值 ≥ 主歌 - 2.0 字（Hook 拆短行属允许写法） |
| Hook | 单行 8-12 字 **或相邻两行合并 8-16 字（拆行 Hook）**                       |
| 画面克制 | 整首 ≤4 句，不设下限（关键词表对齐创作规范 "具象画面点缀" 语义）                        |
| 副歌韵脚 | 取各副歌实例最高统一度 + **逐实例打印统一度明细**供复核（硬门禁 ≥60%）                   |
| 原创性  | n-gram 重复率默认 <10% 为 PASS（GUI 可自由设定 2-8 / 0-50%）             |

评分构成（满分 100）：Hook 20 + 韵脚 15 + 字数 15 + 情绪递进 10 + Call-back 15 + 结构 20 + 画面 5。

判定：≥85 PASS ｜ 60-84 WARN ｜ <60 或硬门禁失败 FAIL。
